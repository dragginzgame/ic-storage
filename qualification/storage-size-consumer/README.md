# Storage Wasm size consumer

Unpublished, production-shaped canister for the matched size study. It uses one
`u64` record type per selected collection and the same application endpoints as
its peer. It contains no benchmark catalogue, timer or verification model.

Run `make benchmark-storage-size` from the repository root. The
[shared benchmark documentation](../ic-storage-benchmarks/README.md#matched-consumer-wasm-size)
owns configuration, protocol, qualification and result interpretation.
