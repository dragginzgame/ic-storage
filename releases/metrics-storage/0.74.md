# Metrics Storage 0.74 notes

## [0.74.0] - 2026-11-09

### ⚠️ Breaking

- Adopt IC Wire 0.19. The adapter's public codec-error variant contains
  `ic_wire::Error` from the new minor; consumers matching or constructing it must
  use that identity. Native codec bytes, checkpoint framing and admission limits
  remain unchanged. No persisted-data migration or backing reset is required.

### 🛠️ Tooling

- Use the workspace's Toko Tooling 0.38.2 selection and the independent
  `qualification/` workspace. Qualification package versions remain private.
