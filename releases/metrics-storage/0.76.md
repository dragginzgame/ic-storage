# Metrics Storage 0.76 notes

## [0.76.1] - Unreleased

Select Storage 0.73.2 following its IC Build 0.83 tooling adoption. This is a
compatible dependency update; Metrics APIs, Wire types and checkpoint bytes
remain unchanged.

## [0.76.0] - 2026-11-11

Adopt IC Wire 0.21's public codec-error identity, selecting 0.21.1; callers matching that type must
select the same minor. Its decoder accepts redundant varints, while encoder
bytes, envelope framing and Metrics state validation remain unchanged. Existing
checkpoint data needs no reset or migration for this dependency change.

Wire's generated TypeScript naming and browser/host traversal changes do not
require generated-client changes in this package.

The mutation qualification now checks semantic re-encoding rather than requiring
every accepted byte sequence to be canonical. Read-only admission and saving an
unchanged state still preserve original bytes without writes. Invalid state,
identity mismatches, trailing bytes and regressions retain rejection coverage.
