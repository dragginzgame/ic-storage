# Metrics Storage 0.76 notes

## [0.76.3] - Unreleased

### ⚡ Performance

Histogram configuration admission and unchanged-state equality now compare
bounds/counts as full-width words while retaining every numeric and configuration
check. Selected 256-bound loads improve 8.6%; unchanged saves improve 22% on the
first call and 34.5% on a second call in the same execution. Matched benchmark
Wasm grows 1,171 total / 1,180 code bytes. Tiny controls change by at most four
instructions. [Profiling, complete results and safety coverage](../../docs/measurements/metrics-histogram-comparisons-2026-11-12.md)
use a fresh Metrics 0.29.12 baseline; they do not compare different supplier graphs.

Checkpoint saves and removals use Storage's explicit discard-result mutations
after existing identity, envelope, shape and continuity checks. Equal checkpoints
still perform no writes. Public APIs and checkpoint bytes are unchanged.
This release requires Storage 0.73.6's discard capability; the supplier-first
release updates the inherited package requirement before adapter publication.
See [#118 — Investigate discard-value mutations for governed stable maps](https://github.com/dragginzgame/ic-storage/issues/118)
and [Storage's qualification](../../docs/measurements/storage-discard-mutations-2026-11-12.md).
The real histogram checkpoint benchmark shows 0.31–0.48% changed-save and
0.20–0.58% removal savings across 1/16/256 bounds and 1/64 rows. Validation remains
the larger cost; generic large-value Map gains are not adapter gains. The matched
checkpoint benchmark shrinks 736 total / 582 code Wasm bytes. Added reproducible
native IO and installed first/second-operation probes; rejected the buffer-prefix
trial because its small selected savings did not justify larger Wasm and regressions.

## [0.76.2] - 2026-11-12

### 🧰 Tooling

Move `src/tests.rs` to `src/tests/mod.rs` so modules with children use directory
module roots. Test contents and Rust module paths are unchanged. Adopt inherited
Toko Tooling 0.39.17 and IC Wire 0.21.4 selections; checkpoint encoding, validation
and public APIs are unchanged.

## [0.76.1] - 2026-11-11

Select Storage 0.73.2 following its IC Build 0.83 tooling adoption. This is a
compatible dependency update; Metrics APIs, Wire types and checkpoint bytes
remain unchanged.

## [0.76.0] - 2026-11-11

Adopt IC Wire 0.21's public codec-error identity, selecting 0.21.1; callers matching that type must
select the same minor. Its decoder accepts redundant varints, while encoder
bytes, envelope framing and Metrics state validation remain unchanged. Existing
checkpoint data needs no reset or migration for this dependency change.

Wire's generated TypeScript naming and browser/host traversal changes do not
require generated-client changes in this package.

The mutation qualification now checks semantic re-encoding rather than requiring
every accepted byte sequence to be canonical. Read-only admission and saving an
unchanged state still preserve original bytes without writes. Invalid state,
identity mismatches, trailing bytes and regressions retain rejection coverage.
