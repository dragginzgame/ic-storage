# Metrics Storage 0.78 notes

## [0.78.0] - Unreleased

### 💥 Breaking

Replace `StoreError::Codec(ic_wire::Error)` with the adapter-owned unit variant
`StoreError::Codec`. Remove the public Wire-error conversion and error source;
callers match `Codec` directly without importing Wire. Malformed-record and
record-size errors retain their existing distinctions. Codec implementation
details are no longer part of the public API.

Adopt IC Wire 0.22.0 internally. Consumers no longer need to align a direct Wire
dependency merely to handle adapter errors.
The `ICMW` checkpoint schema, bounded decoding, semantic validation and governed
allocation contract remain unchanged. No record migration or backing reset is
required. Frozen-row reopening and exact encoded-byte tests qualify compatibility.

Wire remains an adapter serialization dependency; core Storage does not acquire
a production dependency on it. See [the adoption evidence](../../docs/status/current.md#pending-wire-0220-adoption).
