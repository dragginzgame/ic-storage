# Logging Storage 0.72 notes

## [0.72.3] - 2026-11-12

### ⚡ Performance

Checkpoint saves and removals skip Storage's unused previous-value materialization
after Logging's existing validation. Identity, watermarks, text ceilings, no-op
writes and checkpoint bytes are unchanged. Installed query non-persistence,
update/upgrade rollback and reopen retain their qualification.
This release requires Storage 0.73.6's discard capability; the supplier-first
release updates the inherited package requirement before adapter publication.
See [#118 — Investigate discard-value mutations for governed stable maps](https://github.com/dragginzgame/ic-storage/issues/118)
and [Storage's qualification](../../docs/measurements/storage-discard-mutations-2026-11-12.md).

## [0.72.2] - 2026-11-12

### 🧰 Tooling

Move `src/codec.rs` and `src/tests.rs` into their respective `mod.rs` roots so
modules with children have one directory owner. File contents, Rust module paths
and checkpoint behavior are unchanged. Adopt inherited Toko Tooling 0.39.17 and
IC Wire 0.21.4 selections; checkpoint encoding, validation and public APIs remain.

## [0.72.1] - 2026-11-11

Select Storage 0.73.2 following its IC Build 0.83 tooling adoption. This is a
compatible dependency update; Logging APIs, Wire types and checkpoint bytes
remain unchanged.

## [0.72.0] - 2026-11-11

Adopt IC Wire 0.21's public codec-error identity, selecting 0.21.1; callers matching that type must
select the same minor. Its decoder accepts redundant varints. Existing encoder
bytes, discriminator 3, retained-text bounds and Logging restoration validation
are unchanged. This dependency change needs no checkpoint migration or reset.
