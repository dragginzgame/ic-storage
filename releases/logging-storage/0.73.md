# Logging Storage 0.73 notes

## [0.73.0] - Unreleased

### 💥 Breaking

Require Rust 1.100.0 for consumers and for development/release builds.
Collection APIs and retained formats are unchanged; no data reset is required.
Adopt the common compiler and lint policy from [#159](https://github.com/dragginzgame/ic-storage/issues/159).

Adopt Logging 0.25.0. Hosts exchanging Logging values must select its 0.25 line;
discriminator-3 checkpoints and validated restoration remain unchanged.
Existing Storage-owned backing and logging rows require no reset.

### 🧰 Tooling

Inherit the workspace's Toko Tooling 0.40.1 selection. Logging APIs and checkpoint
bytes are unchanged; [Storage's adoption record](../../docs/adoption/storage-tooling.md#toko-0401-adoption)
owns the shared snapshot and qualification evidence.
