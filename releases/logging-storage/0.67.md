# Logging Storage 0.67 notes

## [0.67.0] - Unreleased

### ⚠️ Breaking

Integrate Storage 0.69's direct collection results. Hosts exchanging governed
maps or Storage errors with this adapter must align their Storage dependency.
The adapter retains its genuine checkpoint errors.

Discriminator-3 checkpoint bytes, retained-text admission and restoration semantics
are unchanged. Current Storage 0.68 collection images remain valid; no reset or
data migration is required for this release. See [Storage's API migration](../storage/0.69.md).
