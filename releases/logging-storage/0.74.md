# Logging Storage 0.74 notes

## [0.74.0] - Unreleased

### 💥 Breaking

Replace `StoreError::Codec(ic_wire::Error)` with the adapter-owned unit variant
`StoreError::Codec`. Remove the public Wire-error conversion and error source;
callers match `Codec` directly without importing Wire. Malformed-record and
record-size errors retain their existing distinctions. Codec implementation
details are no longer part of the public API.

Adopt IC Wire 0.22.0 internally. Consumers no longer need to align a direct Wire
dependency merely to handle adapter errors.
Discriminator-3 checkpoint bytes, limits, continuity and validated restoration
remain unchanged. No record migration or backing reset is required. Frozen-byte
and rejection tests qualify the existing schema.

### 📦 Dependencies

Require Logging 0.25.1 or compatible patches; both locks select published 0.25.5.
The adapter's checkpoint contract is unchanged. See
[the adoption evidence](../../docs/status/current.md#pending-product-and-supplier-work).
