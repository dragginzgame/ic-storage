# Storage 0.69 notes

## [0.69.1] - Unreleased

### 🔧 Tooling

- Select Shared Tooling 0.34.0 through root metadata and `toko-tooling.lock`,
  independently of Cargo dependencies. Use `make shared-tooling-update` after
  changing the declared version; deployment refuses mismatched tooling receipts.

## [0.69.0] - 2026-11-08

### ⚠️ Breaking

Ordinary Map, Set, Vector and Cell operations return values directly rather than
always-successful Results. Iterator items likewise return entries or values.
Remove the obsolete outer `?`, `unwrap` or `expect`; preserve Option handling for
missing records. Constructors, reservations and region admission retain genuine
typed errors. Codec and engine failures still trap. Remove the ineffective
`set_node_cache_budget` API and obsolete collection error variants.

Current BTR2/BTN2, SVC1, SCL1 and allocation-directory images are unchanged.
No reset or data migration is required from Storage 0.68. Native unwind poisoning,
IC rollback, backing custody and exclusive leases remain enforced.

### 🧹 Cleanup

Unify Memory and Bound contracts, keep one Vector engine, remove redundant node
representation wrappers and carry canonical admitted keys through bootstrap.
Collection bounds checks are independent of overridable codec convenience helpers.

### 🧪 Testing

Consolidate the benchmark catalogue while preserving the 73-type union and all
five collection forms. The complete 565-case comparison passes 51,768 measured
calls and 53 expected refusals. Native histories cover all supported catalogue
cases across four access patterns and three mutation rounds. Shared IO-counting
fixtures compile for native and Wasm test targets without duplicated counters.

All-five application Wasm is 147,911 bytes versus the retained previous 150,062
and ICSS's 119,378. Instruction comparisons remain workload-dependent; this is
not a universal speedup. Reject the inline-node iterator experiment because it
increases broad benchmark Wasm by 1,134,630 bytes.
See [selected changes and evidence](../../docs/audits/recurring/architectural-reduction-2026-11-08.md).

### 🔧 Tooling

Adopt Shared Tooling 0.31.12 with clearer CLOC output and updated issue closure
policy. Publication and dependency selections remain separately governed.
